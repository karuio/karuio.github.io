中文改写

Eric Seufert 的判断很直接：苹果不该收购 Instinct。

他的起点是亚马逊刚刚宣布，用户可以通过短信和自家代理 Alexa for Shopping 沟通。他认为，苹果已经拥有这条接口。

在他看来，Agent 本身已经是大宗商品。他点名 Perplexity 的 Computer、OpenClaw、Instinct、Muse，并认为字节跳动、谷歌和微软也都会提供类似产品。

一支有动力的团队，用几周时间就能做出一个 Agent。他承认这不是小事，但远谈不上跨越不了的门槛。

真正把 Agent 区分开来的，是分发能力，以及对数据和平台功能的特权访问。苹果已经具备这些。收购 Instinct，在他看来不会带来苹果自己做不到的明显战略优势。Siri 已经有代理能力，也可以通过原生的 App Intents API 连接 iOS 应用。

他还说，今天用来论证苹果该买 Instinct 的理由，12 个月前同样适用于收购 Perplexity。商品化的代理功能本身没有固有价值，它要靠平台覆盖面才能打开。因此他认为，在这个领域，并购不是审慎的增长策略。

原文

Apple should not buy Instinct.

Apple should not buy Instinct.

Amazon just announced that it will allow customers to communicate with its own agent, Alexa for Shopping, via SMS. Apple already owns that interface.

Agents are commodities. Perplexity’s Computer, OpenClaw, Instinct, Muse. ByteDance will offer one, as will Google and Microsoft.

An agent can be built by a motivated team in a matter of weeks; no small development feat, but not an insurmountable hurdle by any means.

Distribution and privileged access to data / platform functionality is what differentiates agents. Apple has that, and buying Instinct provides it with no obvious strategic advantage that it couldn't build itself. Siri already has agentic functionality and can connect to iOS apps with the native App Intents API.

Everything one could argue about the logic of Apple buying Instinct applied 12 months ago with respect to Perplexity. Commodity agentic functionality is not inherently valuable; it’s unlocked with platform reach. M&A is not a prudent growth strategy in this space.
